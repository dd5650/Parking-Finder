삼성 갤럭시 / 안드로이드 설치 방법
  1. 화면 하단에 뜨는 [앱 설치] 또는 [홈 화면에 추가] 버튼을 누릅니다.
  2. 만약 버튼이 보이지 않는다면, 우측 상단 메뉴(⋮) ➔ [앱 설치]를 터치합니다.
  3. 휴대폰 바탕화면에 파킹파인더 앱 아이콘이 자동 생성됩니다!
애플 아이폰 (Safari) 설치 방법
  1. Safari 브라우저 하단 중앙의 공유(⬆️ 사각형 위 화살표) 버튼을 누릅니다.
  2. 메뉴를 아래로 내려 [홈 화면에 추가 (➕)] 항목을 터치합니다.
  3. 우측 상단 [추가]를 누르면 아이폰 홈 화면에 앱이 설치됩니다!
